## 🚀 What's new

The first public release is live! Here's what's included:

### Features

- **Multilingual site (en / zh / ja)** — full i18n with automatic locale detection
- **MDX blog** — write posts in Markdown, served as static pages
- **Newsletter** — double-checked email validation and signed unsubscribe links
- **Cloudflare-native stack** — runs on Workers with D1 (SQLite) and R2 (object storage)
- **Bot protection** — Cloudflare Turnstile on all forms
- **Cookie consent** — analytics and ads load only after explicit consent (GDPR/CCPA)

### Under the hood

- Next.js 16 + React 19, deployed via OpenNext on Cloudflare Workers
- Privacy-friendly by default: security headers and a strict CSP in production

Thanks for being here from day one! 🎉
