## 🚀 新機能

初のパブリックリリースが公開されました!含まれる内容:

### 機能

- **多言語サイト(en / zh / ja)** — 完全な i18n と自動ロケール検出
- **MDX ブログ** — Markdown で記事を書ける静的ページ
- **ニュースレター** — 二重のメール検証と署名付き配信停止リンク
- **Cloudflare ネイティブ構成** — Workers 上で動作、D1(SQLite)と R2(オブジェクトストレージ)を利用
- **ボット対策** — 全フォームに Cloudflare Turnstile を導入
- **Cookie 同意** — 分析・広告スクリプトは明示的な同意後にのみ読み込み(GDPR/CCPA)

### 技術詳細

- Next.js 16 + React 19、OpenNext 経由で Cloudflare Workers にデプロイ
- プライバシーフレンドリーな設計:セキュリティヘッダーと本番環境の厳格な CSP
